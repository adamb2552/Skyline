# CLAUDE.md

Skyline is an original iOS tower‑building simulation (side‑view skyscraper sim). The full spec is in `docs/DESIGN.md`. Read it before starting a milestone.

## Project rules
- Never use the names "SimTower" or "Yoot Tower", or any original assets, sounds, or text from those games. All art and audio must be original or CC0, and recorded in `ASSETS.md`.
- Work one milestone at a time from `docs/DESIGN.md` §7. Do not start the next milestone until the current one's acceptance criteria pass. Track progress in `docs/PROGRESS.md` (milestone, what's done, known issues).
- Keep changes small and commit after each working step with a clear message.

## Architecture rules
- `Packages/TowerCore` is pure Swift and imports only Foundation. No UIKit, SwiftUI, or SpriteKit there.
- The simulation is deterministic: fixed tick, seeded RNG (`SeededRNG`), no `Date()`, no `Double.random`, no system randomness inside systems.
- The UI never mutates simulation state directly. It sends `Command`s; the simulation validates and applies them.
- Content and balance numbers live in `App/Resources/Content/*.json`, not in code.
- Agents are structs in arrays referenced by integer IDs. Avoid per‑agent classes.

## Xcode project
- The Xcode project is generated by XcodeGen. Edit `project.yml`, then run `xcodegen generate`. Never edit `Skyline.xcodeproj` by hand, and don't commit it (it's in `.gitignore`).

## Commands
- Generate project: `xcodegen generate`
- Test simulation: `cd Packages/TowerCore && swift test`
- Build app: `xcodebuild -scheme Skyline -destination 'platform=iOS Simulator,name=iPhone 16' build`
- Headless sim: `cd Packages/TowerCore && swift run sim-cli Scenarios/<name>.json --days 10`
- Lint/format (if installed): `swiftlint` and `swiftformat .`

## Testing
- Every new rule in `TowerCore` (placement, routing, elevator dispatch, stress, economy, rating) gets unit tests.
- Run `swift test` before every commit. Run the app build before finishing a milestone.
- Prefer verifying gameplay with `sim-cli` scenarios over asking the user to tap through the app. When the user must test on device, list exactly what to try.

## Style
- Swift 6 language mode, strict concurrency. iOS 17+ target.
- SwiftUI for menus, HUD, and inspectors; SpriteKit only for the tower view.
- Small files, one type per file where reasonable. Doc comments on public `TowerCore` APIs.
